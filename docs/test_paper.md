# 台灣高中生數位學習動機與學業成效之關聯研究

## ——以自我調節學習為中介變項

**作者：** 林怡君、陳建宏、王淑芬  
**單位：** 國立臺灣師範大學教育心理與輔導學系  
**期刊：** 教育科技與學習（第12卷第2期）  
**發表年份：** 2023年

---

## 摘要

本研究旨在探討台灣高中生數位學習動機與學業成效之間的關聯，並檢驗自我調節學習是否在此關係中扮演中介角色。研究採用問卷調查法，以台灣北、中、南三區共1,247名高中生為研究對象。研究工具包含數位學習動機量表、自我調節學習量表及學業成效測量。

研究結果顯示：（一）數位學習動機對學業成效具有顯著正向影響（β = 0.43, p < .001）；（二）自我調節學習在數位學習動機與學業成效之間具有部分中介效果（間接效果量為0.18，佔總效果的41.9%）；（三）不同性別、學校類型在數位學習動機與自我調節學習策略的使用上均存在顯著差異。本研究建議教師應在數位教學環境中積極引導學生發展自我調節學習能力，以提升整體學習成效。

**關鍵詞：** 數位學習、學習動機、自我調節學習、學業成效、高中生

---

## 一、研究背景與動機

### 1.1 研究背景

隨著資訊科技的快速發展，數位學習（digital learning）已成為現代教育的重要組成部分。尤其在2020年新冠疫情爆發後，全球教育系統被迫加速轉型，台灣高中教育也不例外。教育部統計資料顯示，疫情期間台灣全面推行遠距教學，超過96萬名高中生完全依賴數位平台進行學習（教育部，2021）。

然而，數位學習的普及並未自動帶來學習成效的提升。研究顯示，部分學生在數位學習環境中表現出較低的學習動機與成效（Deci & Ryan, 2000; 林宜親等，2019），這一現象在台灣高中生群體中尤為突出。如何有效提升學生的數位學習動機，進而改善其學業表現，成為教育工作者與研究者亟需解決的重要課題。

### 1.2 研究動機

過去國內外針對數位學習動機的研究，多著重於大學生族群（Wang et al., 2018; 張春興，2020），對高中生的關注相對不足。高中階段是學生從依賴外部動機向內在動機轉型的關鍵時期，此時期的學習態度與習慣對未來的學業發展具有深遠影響（Zimmerman, 2002）。

此外，現有研究多以單一地區或單一學校類型為樣本，缺乏全台灣大規模的系統性調查。本研究動機在於：

第一，填補高中生數位學習動機研究的空缺，提供更具代表性的全台樣本資料。

第二，檢驗自我調節學習（self-regulated learning, SRL）的中介角色。自我調節學習被視為學習成效的關鍵預測因子（Pintrich, 2004），但在台灣高中數位學習情境中的作用尚未被充分探討。

第三，比較不同學校類型（公立、私立、完全中學）及不同地區學生在數位學習動機上的差異，為差異化教學政策提供實證依據。

### 1.3 研究問題

本研究提出以下四個研究問題：

1. 台灣高中生的數位學習動機整體狀況為何？
2. 數位學習動機對學業成效是否具有顯著影響？
3. 自我調節學習是否在數位學習動機與學業成效之間具有中介效果？
4. 不同性別、學校類型及地區的學生在數位學習動機與自我調節學習上是否存在顯著差異？

## 二、文獻回顧

### 2.1 數位學習動機相關理論

本研究以自我決定理論（Self-Determination Theory, SDT）（Deci & Ryan, 1985）與期望價值理論（Expectancy-Value Theory）（Eccles et al., 1983）作為理論基礎。自我決定理論主張，個體的動機可分為內在動機（intrinsic motivation）、外在動機（extrinsic motivation）及無動機（amotivation）三類。在數位學習情境中，當學生感受到自主性、勝任感與關係連結三項基本心理需求被滿足時，其內在學習動機較高（Ryan & Deci, 2020）。

期望價值理論則強調，學生對學習任務的「期望」（預期自己能成功完成任務的信念）與「價值」（認為任務對自己重要的程度）共同決定其學習投入程度。Eccles等人（1983）進一步將任務價值細分為內在價值、效用價值、成就價值與成本四個次向度。

### 2.2 自我調節學習

自我調節學習指個體主動設定學習目標、選擇策略、監控學習歷程並評估成效的過程（Zimmerman, 1989）。Pintrich（2004）提出的自我調節學習模型包含認知、動機/情感、行為及情境四個層面的調節。在數位學習環境中，自我調節學習尤為重要，因為數位環境提供了更大的學習自由度，同時也需要學生具備更強的自我管理能力（Cho & Shen, 2013）。

### 2.3 數位學習與學業成效

過去研究對數位學習與學業成效的關係結論不一。部分研究顯示數位學習對成效有正向影響（Means et al., 2013），另一些研究則指出，若缺乏適當的教師引導與學習支持，數位學習可能導致成效下降（Kentnor, 2015）。本研究認為，這些矛盾結果可能源於中介變項（如自我調節學習）的忽略，故本研究特別納入自我調節學習作為中介變項進行探討。

## 三、研究方法

### 3.1 研究設計

本研究採用橫斷面問卷調查設計（cross-sectional survey design），並以結構方程模型（Structural Equation Modeling, SEM）進行資料分析。

### 3.2 研究對象

研究對象為台灣北部（台北市、新北市）、中部（台中市、彰化縣）及南部（高雄市、台南市）共18所高中的高一至高三學生。採用分層叢集抽樣法（stratified cluster sampling），按地區比例抽取學校，再以班級為單位進行全班施測。

共發放問卷1,350份，回收有效問卷1,247份，有效回收率為92.4%。樣本組成如下：

- 性別：男性621人（49.8%），女性626人（50.2%）
- 年級：高一405人（32.5%），高二421人（33.7%），高三421人（33.7%）
- 學校類型：公立普通高中8所（710人），私立高中6所（321人），完全中學4所（216人）

### 3.3 研究工具

#### （一）數位學習動機量表

本研究改編自Ryan與Deci（2020）的學習動機量表，並依數位學習情境進行調整，共24題，分為內在動機（8題）、外在動機（8題）及無動機（8題）三個次量表，採用李克特六點量尺（1=完全不符合，6=完全符合）。本研究樣本之整體Cronbach's α係數為.89，各次量表α係數介於.81至.87之間，具良好信度。探索性因素分析結果支持三因素結構，解釋總變異量為64.3%。

#### （二）自我調節學習量表

改編自Pintrich等人（1991）的學習動機策略問卷（MSLQ），選取自我調節學習相關題項，共30題，包含目標設定（6題）、學習策略使用（12題）、自我監控（6題）及時間管理（6題）四個向度，採用李克特七點量尺。整體Cronbach's α為.91，各向度α係數介於.78至.88之間。

#### （三）學業成效

以學生最近一學期的學期成績（五科平均：國文、英文、數學、自然、社會）作為學業成效指標，由各校教務處提供官方成績資料，以百分制記錄。

### 3.4 資料分析

資料分析步驟如下：

1. **描述統計分析**：計算各變項的平均數、標準差及偏態、峰度。
2. **信效度分析**：進行驗證性因素分析（CFA）以確認量表建構效度，計算各量表Cronbach's α係數。
3. **相關分析**：以Pearson相關係數檢驗各變項間的關係。
4. **結構方程模型**：以AMOS 26.0進行路徑分析及中介效果檢驗。中介效果以Bootstrap法（抽樣次數5,000次）估計間接效果95%信賴區間。
5. **多變量變異數分析（MANOVA）**：比較不同性別、學校類型及地區在各變項上的差異。

## 四、研究結果

### 4.1 描述統計

各變項描述統計結果顯示，研究樣本的數位學習動機整體平均值為3.87（SD = 0.92），其中內在動機平均最高（M = 4.12, SD = 0.88），外在動機次之（M = 3.91, SD = 1.03），無動機最低（M = 2.58, SD = 1.14）。

自我調節學習整體平均值為4.23（SD = 0.87），顯示受試學生具有中等偏高的自我調節學習能力。學業成效平均分數為73.6分（SD = 12.4），略高於全國高中生平均成績（70.2分）。

### 4.2 相關分析

表1呈現各變項間的相關係數。數位學習動機（尤其是內在動機）與自我調節學習（r = .61, p < .001）及學業成效（r = .47, p < .001）均呈顯著正相關。自我調節學習與學業成效亦呈顯著正相關（r = .54, p < .001）。無動機則與自我調節學習（r = -.48, p < .001）及學業成效（r = -.39, p < .001）呈顯著負相關。

### 4.3 結構方程模型分析

結構方程模型整體適配度指標：χ²/df = 2.14（< 3.0），CFI = .96（> .95），RMSEA = .048（< .06），SRMR = .051（< .08），顯示模型具良好適配度。

路徑分析結果顯示：

- 數位學習動機（內在動機為主）對學業成效的直接效果：β = 0.26（p < .001）
- 數位學習動機對自我調節學習的影響：β = 0.58（p < .001）
- 自我調節學習對學業成效的影響：β = 0.31（p < .001）
- 數位學習動機對學業成效的總效果：β = 0.43（p < .001）
- 間接效果（透過自我調節學習）：β = 0.18（95% CI [0.14, 0.23]），佔總效果41.9%

Bootstrap分析確認間接效果95%信賴區間不含零，顯示自我調節學習在數位學習動機與學業成效之間具有顯著的部分中介效果。

### 4.4 性別與學校類型差異

MANOVA分析結果顯示，性別在數位學習動機（Wilks' Λ = .94, F(3, 1243) = 8.72, p < .001）及自我調節學習（F(4, 1243) = 11.34, p < .001）上均達顯著水準。女生在內在動機（M = 4.28 vs. M = 3.96, d = 0.37）與自我調節學習（M = 4.41 vs. M = 4.05, d = 0.42）上均顯著高於男生。

學校類型方面，公立普通高中學生的學業成效（M = 76.3）顯著高於私立高中（M = 69.8）及完全中學（M = 71.2），但三類學校學生在數位學習動機上並無顯著差異（p = .21），顯示數位學習動機的影響並不因學校類型而有所差別。

地區比較方面，北部學生（M = 75.1）的學業成效顯著高於中部（M = 72.8）及南部（M = 71.9）學生，但三地區在內在動機上的差異不顯著（p = .34）。

## 五、討論與結論

### 5.1 主要發現討論

#### 發現一：內在動機是提升數位學習成效的核心

本研究確認了內在動機在數位學習中的核心地位，與Ryan和Deci（2020）的自我決定理論預測相符。值得注意的是，外在動機（如成績壓力、家長期望）對學業成效的影響相對較小（β = 0.11, p = .03），這提示我們：在數位學習情境中，單靠外部獎懲機制難以持續提升成效，培養學生對學習本身的興趣與熱情才是根本之道。

#### 發現二：自我調節學習是關鍵橋樑

自我調節學習在數位學習動機與學業成效間的部分中介效果，揭示了一個重要的教育意涵：即使學生具有高度的數位學習動機，若缺乏有效的自我調節學習策略，其動機未必能有效轉化為實際的學業成就。此結果與Cho和Shen（2013）的研究相呼應，顯示數位學習環境中的「動機—策略—成效」三角關係具有跨文化的穩定性。

#### 發現三：女生的自我調節優勢

女生在自我調節學習上的優勢（d = 0.42）可能與社會化過程中女性被期待表現出更多計畫性與自律性有關（Zimmerman & Kitsantas, 2005）。然而，此性別差異是否源於天生特質或後天培養，仍需進一步的縱貫研究加以釐清。

### 5.2 教育實踐建議

基於上述研究發現，本研究提出以下教育實踐建議：

1. **設計具自主性的數位學習任務**：教師應提供學生選擇學習路徑、設定個人目標的機會，以支持內在動機的發展。

2. **明確教導自我調節學習策略**：在導入數位學習平台時，應同步提供時間管理、目標設定、學習策略等相關訓練，而非假設學生已具備這些能力。

3. **關注男學生的動機與自我調節**：考量男女生在自我調節學習上的差異，學校輔導人員應特別關注男生的數位學習適應情況，提供針對性的協助。

## 六、研究限制

本研究存在以下幾項限制，需在解讀結果時加以考量：

**第一，橫斷面設計的因果推論限制。** 本研究採用一次性問卷調查，無法確立各變項間的因果關係。數位學習動機與學業成效之間可能存在雙向影響（即高學業成效可能反過來強化學習動機），縱貫研究設計將有助於釐清此問題。

**第二，自陳量表的主觀偏誤。** 數位學習動機與自我調節學習均採自陳量表測量，受試者可能受社會期許效應影響而高估自身的動機與學習策略使用情形。未來研究可考慮搭配學習日誌、學習平台行為資料等客觀指標，以提升測量效度。

**第三，樣本代表性的局限。** 本研究雖涵蓋台灣北、中、南三區，但樣本主要來自都會區高中，對偏遠地區或離島學校的代表性不足。此外，研究對象均為就讀一般高中的學生，職業學校及綜合高中學生的情況可能有所不同，研究結果不宜過度推論至這些族群。

**第四，學業成效指標的單一性。** 本研究以學期平均成績作為學業成效的唯一指標，未涵蓋批判思考、創意解題等較難以量化的深層學習成效。未來研究可考慮採用更多元的成效指標，如各科表現差異、問題解決能力測驗等。

**第五，數位學習情境的多樣性未加以區分。** 不同數位學習平台（如非同步影片學習、同步視訊課程、互動式學習系統）對動機與成效的影響可能有所不同，本研究未加以細分，可能使結果解讀受限。

---

## 七、結論

本研究以1,247名台灣高中生為樣本，系統性地探討了數位學習動機、自我調節學習與學業成效之間的關聯。研究結果確認了三者之間的正向關聯，並揭示了自我調節學習在此關係中的部分中介作用。這些發現不僅豐富了華語地區數位學習動機的研究文獻，也為教育工作者設計更有效的數位學習環境提供了實證依據。

未來研究應朝以下方向延伸：（一）採用縱貫設計以建立因果推論；（二）納入更多元的成效指標；（三）探討教師教學風格作為調節變項的可能作用；（四）擴展樣本至職業學校及偏遠地區學校。
